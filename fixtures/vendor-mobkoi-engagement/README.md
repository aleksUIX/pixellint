# The pack covers the inspected landing-tag sender.

The source is the public SDK linked by Mobkoi's own integration guide. Its
inspected 1.0.0 artifact has SHA256
`4f71000675249c21f048bc79e8915f78bd55cf033edb813cde7129b460180892`.
Run the offline oracle against that source file:

```sh
node fixtures/vendor-mobkoi-engagement/source-replay.mjs /path/to/tag.min.js
```

Every network API is replaced by a local recorder. The replay covers initial
and resumed sessions, page visibility and history changes, all flush reasons,
the fetch fallback, consent gates and configured endpoints. Golden fixtures
include 10 captures generated by this independent sender replay.

The manifest checks only the three exact engagement paths at the default host.
Source-specific field spelling and completeness findings are warnings. `iid`
stays opaque and optional; zero, negative and exponent active-time values are
accepted. URL schemes, custom fields, duplicate carriers, response acceptance,
session relationships and account validity remain open. The source does not
emit consent query flags, a required body or a custom header.

The separate `/track/impression`, `/track/video_start`, `/track/video_complete`
and `/track/click` VAST collectors are outside this pack. No saved VAST row
is projected to gain vendor checks from this engagement profile.
