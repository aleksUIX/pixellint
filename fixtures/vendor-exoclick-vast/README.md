# The pack checks bounded VAST registration templates.

The official VAST guide publishes impression, error and progress vregister
examples on its named default syndication placeholder. ExoClick's official
documentation links `https://a.magsrv.com/ad-provider.js`, whose inspected
configuration binds syndication to `s.magsrv.com`. This establishes the current
host attribution and default service role, without a whole receiver schema.

Presence advice is limited to source-supported action, zone, event and progress
branches and remains warning-level. The opaque data key is optional because an
example cannot establish universal requiredness. No equivalence with d or dg
is inferred. Identifier grammar, payload meaning, accepted types, duplicate
policy, unlisted actions/events and request transport remain open.

The guide also publishes click.php?data=abcd. No executable carrier contract
has been established for click requests, including d-carrier variants. The
pack therefore does not select click.php or cimp.php. They can retain vendor
attribution while remaining outside vendor field checks.

Golden fixtures preserve public registration examples, native omission cases,
carrier-free impression/progress branches, unknown opaque extra fields,
duplicate-discriminator uncertainty and excluded click paths. The synthetic
carrier variants test explicit deferral. They do not prove aliases or receiver
acceptance from saved observations.
